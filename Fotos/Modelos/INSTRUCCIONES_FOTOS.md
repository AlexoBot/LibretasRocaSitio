# Cómo reemplazar las imágenes del catálogo

1. Coloca aquí las fotografías reales de tus libretas.
2. Usa nombres simples, sin espacios ni acentos. Ejemplo: `libreta-verde-reciclada.jpg`.
3. Abre `Scripts.js` y busca el arreglo `PRODUCTOS`.
4. Cambia el valor de `imagen` por el nombre del archivo nuevo.
5. Si quieres usar las mismas tarjetas sin editar código, reemplaza los SVG existentes conservando exactamente los mismos nombres.

Formatos recomendados: `.jpg`, `.webp` o `.png`.
Tamaño sugerido: 1200 x 1200 px o similar.
